# W4 delivery — left conversation anchoring

## Root cause

Screenshot `20261020T125507Z-image.png` (library editor, left “AI 助手”, empty thread): the composer sat under the intro copy with a tall empty gap below.

The pane had a real height. The chat did not. Path:

`SplitWorkspace` detail layer → `LiveReactNode` fragment → `PluginThemeScope` (background/text only) → `PluginAgentPanel` / `FunctionAgentChat` (`h-full`).

`height: 100%` of an auto-height wrapper collapses to content. The column became intro + composer. Leftover pane space appeared *below* the dock. Long threads would also scroll the whole pane instead of only the transcript.

`use-inline-advanced-agent*` does not exist. Compact split was `md:flex` only, so below `md` the root was block and the left pane was content-sized again.

b12 still owns `bodyClass` `overflow-y-auto` as the leftover scroller. Control panels must not be forced to `min-h-full`. Stretch is gated on `[data-agent-conversation]`.

## Fix

Shared tokens in `src/shell/agent-conversation-layout.ts`:

- column: `flex h-full min-h-0 flex-1 flex-col`
- transcript: `min-h-0 flex-1 overflow-y-auto`
- dock: `mt-auto shrink-0`, last child
- host: `[&:has([data-agent-conversation])>*]:flex|h-full|min-h-0|flex-1|flex-col`

Wired through FunctionAgentChat (agent tab), PluginAgentPanel, agent drawer factory, SplitWorkspace left layers (and solo body), OperatorConsole ops slots, AgentConsole chat slot. LeoComposer card is `shrink-0` so it cannot steal the transcript. Split root is `flex flex-col md:flex-row` so compact widths get a real pane height from the existing flex-basis.

No integrity, CAS, origin, or permission checks were touched. W3 header/inline shell and theme CSS were not edited.
