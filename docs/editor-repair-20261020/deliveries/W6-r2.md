# W6-r2 delivery — valid source load and actual plugin command effects

## Root causes

Round 1 only refused at the route. Owned cores could still blank internally, and website/design admission treated every durable item without inline meta as a permanent failure even when an authorized artifact/media URL existed.

1. **Image.** `use-fabric-image-editor.save()` cleared `sceneDiagnostic` then snapshotted whatever was on the canvas. There was no `sourceReady`. Retry did not exist on the hook.
2. **Website / design local.** Sync admission failed closed for durable items missing inline JSON. `projectFromItem` still returned `blankDesignDocument` on parse miss. Web default already sends those items to the hosted iframe (`preferLocal === false`); local cores (`next` / desktop / `local-editor-cores`) must hydrate `editor_project_url` / source rendition via `fetchMediaBlob`.
3. **Workflow.** `graphFromItem` returned `{ nodes: [], edges: [] }` whenever `meta.graph` was missing, then flush could persist that empty graph. Agent chips parked without a human stamp, but there was no user-facing add-node action.
4. **Hosted deck.** `DeckHostedRoute` documented that it did not send `selection-command`. Edit-bar insert/format never reached the adopted postMessage API.
5. **GameRoute.** `iterate` listed `admitted.error` in hook deps while `admitted` can be `{ ok: true }` (V1 TS2339).
6. **Video timeline.** Remote project fetch existed, but a failed load had no Retry that refetched.

Integrity, CAS, origin, and permission checks were not loosened. Loading failure still never becomes a successful blank save.

## Dispatch contract (website / design)

Web default stays hosted embed (`preferLocalRemoteEditor("website"|"design-canvas") === false` → `localRemoteEditorWorkbenchChoice(false) === "hosted-embed"`). `EmbeddedRoute` still mounts `WebsiteLocalRoute` / `DesignCanvasLocalRoute` only when the local-core flag is on. When that flag is on, durable items without inline meta load the stored JSON through `fetchMediaBlob`; they are not a permanent error panel.

## Fixes

- Image hook exports `sourceReady` + `reload`; `save()` uses `imageSaveAdmitted` and no longer clears a failed diagnostic before snapshotting. ImageRoute persists only when admitted and shows `EditorSourceFailurePanel` with a real reload.
- Website/design: `plan*Source` + `hydrate*Source` load wrapped or raw stored JSON. Malformed inline still fail-closed. Retry bumps nonce and refetches.
- Design hook no longer falls back to `blankDesignDocument` on parse/load failure.
- Workflow: durable missing graph/URL fails closed; valid inline/remote graph hydrates; `workflow.add-node` and the 加节点 button mutate; flush refuses `sourceReady: false`. Agent chips still park without `user|human|l1|l2`.
- Hosted deck sends `selection-command` with envelope `origin: "user"`. Insert (`edit-text`) and format (`fill`) go through `hostedDeckSelectionCommandEnvelope`. Stale selection, read-only, and missing human stamp stay rejected. Origin set was not widened.
- Website Puck and design Fabric command surfaces call existing session/document helpers and change the document.
- Game **play preview** stays without a command surface (intentionally non-editable). Code page run/stop/reload already call `planGamePreviewControl`.
- Video timeline Retry refetches the project URL.
- GameRoute narrows `admitted.error` off the `{ ok: true }` branch.

No website / video / pptist-hosted edits. No browser / production / push. No child agents.
