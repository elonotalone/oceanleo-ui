# W1 delivery — document source import / richdoc normal-pro

## Root causes

Screenshot item `21c1e4d9-0818-4bbe-ae33-b4d01a5beafd` is a typed `document` whose `source_format` is `md` (filename `需签字盖章页清单.md`). All four renditions are the same markdown bytes. Library preview shows the table because `DocumentViewer` fetches `item.url || item.previewUrl` (signed access URL).

Edit opened empty and then tried to save, which integrity correctly rejected. Proven causes in owned code:

1. **Wrong URL.** `richDocSourceUrl` preferred `artifact.renditions.source.url`, which is the gateway source-tree `/source-tree/@source`. `fetchMediaBlob` refuses that path. The viewer’s signed preview URL was only a last fallback.
2. **Empty success / false ready.** An empty project JSON or an empty collab room could mark `sourceReady` with no body. Autosave then submitted blank bytes; integrity failed (preserved, not weakened).
3. **Pro handoff treated every non-json URL as Word** and ran `fromDocx` conversion. Markdown/HTML/text entered Umo already converted.
4. **Native JSON was not an import format.** `.json` / `tiptap-json@1` / `umo.tiptap.v1` fell through to “unsupported”.
5. **Office hint leaked source-tree** into `useEditorHandoffSource`, so pro could inherit the unreadable grant instead of the preview URL.

## Fixes

- Select the same browser-safe document URL the preview uses. Never prefer source-tree or a cover image.
- Detect format from `source_format` / filename / source-full media, not preview/thumb image types.
- Load HTML, markdown, text, docx, and native JSON. Empty project JSON falls through to the original file. Existing documents never become a blank ready editor.
- Collab may inherit readiness only when the room already has content.
- Hosted load uses `loadRichDocHostedState`: no silent Umo conversion; empty inline handoff is refused.
- Normal-face handoff waits for ready and will not flush dirty empty loads.
- Umo bridge: `selection-command` sink + hosted plugin command surface. `umo-hosted` already implements the command; it was not modified.

Integrity, CAS, origin, and permission checks were not loosened.
