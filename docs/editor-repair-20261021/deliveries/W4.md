# W4 delivery — download icon matches share/favorite

Date: 2026-10-21
Repo: `/root/projects/oceanleo-ui` `main`

## Root causes

1. **Filled download circle.** `AdvancedWorkspaceActionBar` passed `variant="secondary"` to `IconButton`. `IconButton` defaults `pill={true}`, so secondary’s surface fill plus `rounded-full` is a filled circle. Share/favorite omit `variant` and therefore render `ghost` (transparent, linear icon).
2. **Deck X/Y on the primary bar (same class as the image screenshot).** Deck geometry number fields lived inline in `DeckContextToolbar`. They already used `slot: "inspector"`, but that contract was not imported by a test. They now come from `deckObjectGeometryControls`, which is inspector-only (`placement: "more"`, `slot: "inspector"`). `isCompactSelectionControl` excludes inspector-slot controls, so X/Y (and W/H) are not compact number fields.

Plugin chrome: `PluginGlobalRow` only mounts `AdvancedWorkspaceActionBar`. `PluginChromeFrame` header icon actions use `ICON_ACTION_CLASS` (`rounded-xl`, no surface fill), not `IconButton variant="secondary"`. No edit there. `editor-item-social-chrome.tsx` left read-only; no class share required.
