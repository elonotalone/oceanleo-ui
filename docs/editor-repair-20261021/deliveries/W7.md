# W7 delivery — design canvas, game, embedded record a person edit

## Root causes

W2 already refuses autosave unless `userMutationGeneration > 0`. Design canvas, game code, and hosted embed still marked dirty/revision on load-adjacent paths and never recorded a person edit, so a real edit never autosaved (fail-closed).

- Design canvas: `commit` / undo / redo bumped `revision` (`dirty: sourceReady && revision > 0`) with no `recordUserMutation`. Load `setRevision(0)` must stay silent.
- Game: `bump()` is shared by textarea typing, `ytext.observe(pull)` (local and remote), agent `writeThrough` / `writeSource`, and recovery restore.
- Embedded: `handleDirtyChange(true)` runs for iframe dirty including init/handshake echoes; `handleRecoveryResult` calls `setDirty(true)` for restore.

## Fix

Named helpers in the owned files call `recordUserMutation(userEditItemKey(item))` only on the person path.

### Design canvas

`applyDesignCanvasUserEditSession(item, kind)` from `commit` (`applyProject`), person undo, and redo. Kind `load` on the identity hydrate that zeros revision does not increment.

### Game

`applyGameUserEditSession`:

- `{ kind: "local-type" }` from textarea `onChange`.
- `{ kind: "ytext-observe", origin }` from `pull` only when origin is `Symbol("oceanleo-collab-textarea-local")` (the `bind-textarea.ts` stamp; not exported, matched by description).
- `writeThrough` (`GAME_EXTERNAL_ORIGIN`), restore, un-evented load `pull()`, and remote/undefined origins do not increment. `bump()` itself does not record.

### Embedded hosted

`applyEmbeddedUserEditSession` from `handleDirtyChange` and recovery restore. Records only when `dirty === true`, hosted core is already open, handshake is ready, not restoring, and not an init / same-revision handshake echo. Website `autoSave` stays off (`hostedMediaType !== "website"`). `WebsiteLocalRoute` `autoSave: false` was not changed.
