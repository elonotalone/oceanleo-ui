# W1 delivery — document opens with body; save matches format

Date: 2026-10-21
Repos: `/root/projects/oceanleo-ui` `main`, `/root/projects/umo-hosted` `main`

## Root causes

1. **Save MIME was Word for every richdoc.** `persistUmoPayload` and `use-rich-doc-editor` `save()` sent `RICHDOC_SOURCE_FORMAT=docx` / Word media type. A `source_format=md` library item (screenshot `21c1e4d9-0818-4bbe-ae33-b4d01a5beafd`) was rejected even when the canvas had the table.
2. **Signed preview 410 had no retry on the editor load path.** `fetchMediaBlob` uses `cache: force-cache` and throws `媒体加载失败 HTTP 410`. The library viewer showed 「刷新安全地址」; Edit/Umo did not mint a fresh rendition URL.
3. **Failed hosted load still inited Umo.** `loadRichDocHostedState` failure set `source=null` but the iframe stayed and received `init`, so an empty Umo looked like a new document.
4. **Markdown handoff waited on office source-tree.** `useEditorHandoffSource` always joined `useOfficeArtifactSource` (`full` = source-tree). Markdown/html/text can open from the preview/access URL.
5. **Umo native Save had no `onSave`.** Editor 11.1.1 default throws `Key "onSave": Please set the save method`. Host persist already existed as `save-request` → `recovery-snapshot` → `persistUmoPayload`.

## Fix

- `richDocPersistTarget` / `createRichDocDeliveryFile`: md/html/txt keep admitted text types; docx stays Word; untitled drafts still default to docx.
- `fetchMediaBlobRefreshing` + `signedMediaRefreshPurpose`: one 410 → `refreshArtifactRendition` (preview for access URLs) → retry `no-store`. Injected `fetchText` that throws HTTP 410 is retried once. MIME/CAS/origin checks unchanged.
- Hosted load: no `init` when `source == null`; overlay `data-editor-source-failure` covers the iframe (iframe remains in the DOM). Native Umo save ids `umo-save-*` persist through the host snapshot path and get `save-result`.
- `useEditorHandoffSource` waits on office bytes only for `docx`/`pptx`.
- `umo-hosted` `createUmoHostedSave` implements `onSave`; init no longer emits dirty.
- `recordUserMutation` (W2, `src/shell/user-edit-session.ts`) on hosted Umo `dirty` after source is loaded and on Tiptap `onUpdate` that is not remote y-sync.

Operator artifact `21c1e4d9-0818-4bbe-ae33-b4d01a5beafd` was not written.
