Preview can show the table; Edit/Umo is blank; autosave was sending `application/vnd.openxmlformats-officedocument.wordprocessingml.document`. Preview also 410s signed media (`媒体加载失败 HTTP 410`) until 「刷新安全地址」. Do not save over this item.

`RICHDOC_SOURCE_FORMAT` / `RICHDOC_SOURCE_MEDIA_TYPE` in `use-rich-doc-editor.ts` and `persistUmoPayload` currently hardcode docx. That is why a markdown item is rejected even if the canvas had body.

`RichDocHostedRoute` still mounts the Umo iframe when `loadRichDocHostedState` fails (`setSource(null)` but iframe `src` stays). Empty Umo then looks like a new document.

`fetchMediaBlob` uses `cache: force-cache` by default and throws on HTTP 410. The library viewer retries a fresh signed URL; the editor load path does not.
