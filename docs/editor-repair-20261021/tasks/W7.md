### Design canvas

`commit` (the function `applyProject` points at) and person undo/redo that bump `revision`. Load identity effect that `setRevision(0)` must not record. `dirty: sourceReady && revision > 0` currently looks like load-dirty if anything increments revision during hydrate — recording only inside `commit` / person undo-redo is the fix.

### Game

`bump` is used both for local typing (via `ytext.observe(pull)` after `bindTextarea`) and for remote Yjs. Record only when the change origin is the local binding, not a remote transaction. `writeThrough` is agent/external — do **not** record there. Look at `src/shell/collab/bind-textarea.ts` for how local origin is stamped; reuse it, do not invent a second origin scheme.

If local typing always goes through the textarea binding and `pull` cannot see origin, record from the binding's local write callback instead of from `observe`.

### Embedded hosted

`handleDirtyChange(true)` after the hosted core is open and handshake-ready, matching `RichDocHostedRoute`: skip init / recovery restore / open handshake that only echoes dirty. Record when a person edit in the iframe reports dirty.

`setDirty(true)` in recovery restore must **not** record.

Website hosted still has `autoSave: false` for Apply — do not turn autosave on for website.
