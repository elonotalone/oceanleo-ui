## Root

`AdvancedPersistenceController.observe` schedules a flush when `dirty && revision changed`. Editors bump revision and/or dirty during load (Fabric `setLoading(true)` + scene hydrate; Umo empty document). Autosave then runs, the image stage paints 「正在载入对象化图片画布…」 again, and documents try to publish a blank/wrong MIME file.

Operator rule: autosaving **must** exist only after a real change, in **every** editor.

## Done when

1. `observe({ dirty: true, revision: 1, userEdited: false })` does **not** schedule `flushRevision`. Same with omitted `userEdited` (default false).
2. After `userEdited: true` (or generation > 0), dirty+revision change does schedule, existing debounce/retry/integrity-failed-not-retryable behavior remains.
3. Workbench passes `userEdited` from the shared session. `SelectionCommandGate` successful **user** commands call `recordUserMutation`. Remote/collab `origin` that is not user must not.
4. Changing the open item resets the generation to 0.
5. Existing W2 persistence tests still pass, plus new `tests/W2-20261021-*.mjs`.
6. Delivery committed.

Do not weaken integrity-failed handling.
