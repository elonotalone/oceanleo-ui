## What to call

```ts
import { recordUserMutation, userEditItemKey } from "../user-edit-session";
recordUserMutation(userEditItemKey(item));
```

### Video timeline

The `apply` that does `setDirty(true)` after a document inequality (history commit) is the person path. Do not record on source-load recovery that only restores bytes.

### Video designcombo

`commit` and the person's convert/toolbar writes. Do not record on the load effect.

### Video canvas / workflow

`applyVideoCanvasCommand` from a control the person clicked (the 「加节点」 button and any other local graph write). `dirty: editRevision > 0` currently fires after load-revision too — recording only on the person command is the fix. Do not record when hydrating the graph.

### Audio

`use-audio-mutations.ts` after a successful local operation (`setDirty(true)`). `AudioPlaylistStage` `bump` if that is a local person write (trim/delete/gain). Leave remote-apply alone.

### PDF

`use-pdf-edit-engine.ts` after a local annotation/mutation (`setDirty(true)`). Undo/redo restore of the person's history may record. `replaceBytesSilently` in `use-pdf-workbench.ts` records only when `markDirty !== false` **and** the caller is a person edit, not a silent source replace.

### Chart

`mutate` and `applyHistoryDocument` (undo/redo). **Not** `applyRemoteDocument`.

### 3D

`markDirty` in `use-model3d-workbench.ts` if that function is only used for local gizmo/sidecar edits. If bootstrap also calls it, split: local helper records, bootstrap does not.

## Done when

1. Person-path mutation in each owned editor increments `userMutationGeneration`.
2. Load / remote / silent replace paths in owned files do not.
3. `tests/W6-20261021-*.mjs` prove this by calling the live mutate/commit/markDirty helpers (export a tiny named helper in the same file if the hook is not importable). Do not pass by grepping a string.
4. Delivery committed on `main` with explicit paths. No `git add -A`. No CSS. No push.
