# W01 — Shell core: Pro allowlist, routing, registries, chart removal, shell-iframe removal

Goal: after this, the shell only offers a Pro page for grid/pdf/website, routes every editor to an
in-page native route, has no chart editor, and has no code path that mounts a third-party/sub-site
web app as an editor.

Owned cluster (oceanleo-ui/src/shell unless noted):
- `plugin-chrome/*` (plugin-pages.ts, plugin-mode.tsx, plugin-mode-store.ts, page rows…),
  `InlineAdvancedWorkbenchHeader.tsx`, `inline-advanced-shell-parts.tsx`, `AdvancedWorkbenchShell.tsx`
  (only the mode/pages wiring), `advanced-editor-adapter.ts`.
- `AdvancedContentWorkbench.tsx`, `workbench-routes.ts`, `editor-preload.ts`, `advanced-drafts.ts`,
  `advanced-session.ts`, `editor-core-flags.ts`, `w10-editor-mounts.ts`, `client-editor-adapters/registry.ts`,
  `plugin-theme.tsx`, `workbench-capability-registry.ts`, `use-advanced-autosave.ts` (chart line only).
- `hosted-editor-origins.ts`, `hosted-local-origin.ts`, `hosted-editor/*`, `editor-protocol.ts`,
  `editor-sandbox-origin.ts`, `family-embed-origin.ts`, `use-prefer-local-editors.ts`,
  `workbench-embed.tsx`, `advanced-routes/EmbeddedRoute.tsx`, `advanced-routes/mode-switch-gate.tsx`,
  `advanced-routes/UnsupportedRoute.tsx`.
- Chart: `chart-editor/` (whole dir), `advanced-routes/ChartRoute.tsx`, `collab/adapters/chart.ts`.
- Cross-editor tests (registries, flags, theme ids, page rows, w10 mounts, hosted origins, chart tests,
  embedded route tests) and a new guard test.

Not yours: each editor's own stage/route files (W02–W11), `library-viewers.tsx` (W06),
`ImageRoute`/`DesignCanvasLocalRoute` internals (W08), `WebsiteLocalRoute` internals (W09),
`GridUniverStage` (W10), `GameRoute` (W11), i18n messages, package.json, public barrels.

Steps:
1. Pro allowlist per 00-dispatch contract: `PRO_PAGE_EDITORS` in plugin-pages.ts; `buildPluginPages`
   gets the plugin id and omits the pro page otherwise; plugin-mode-store returns `normal` for
   non-Pro editors regardless of persisted state; any toggle/tab rendering respects it. Grid's label
   stays "Univer"; pdf/website keep working.
2. Delete chart editor end to end (route, adapter `chart-editor@1`, theme id, flags, mounts, collab
   adapter, autosave special-case, registry rows, preload, capability registry). A Library item that
   declared `chart-editor@1` must resolve to a read-only/unsupported route with a plain message — no crash.
   Echarts may still be used elsewhere (check before requesting dependency removal).
3. Remove hosted editor plumbing: entries for slides/docs/audio/3d/game-ide/flow in
   `hosted-editor-origins.ts`, `editor-core-flags` `hosting: "hosted"` rows, `w10-editor-mounts` rows for
   DeckHostedRoute/RichDocHostedRoute/AudioHostedFrame/Model3DHostedFrame. Editor owners delete those
   component files; you remove every registry/flag/mount reference. `mcp-apps/protocol.ts` imports
   hosted origins — MCP app frames are UGC sandboxes, not editors: keep them working and keep their
   trust checks exactly as strict (run the security gate first; propose to parent before changing any
   trust check).
4. EmbeddedRoute: remove the sub-site editor iframe fallback (`AdvancedWorkbenchShell` + iframe path at
   the end of EmbeddedRoute). website → WebsiteLocalRoute, video canvas → VideoCanvasRoute,
   design canvas → image route/ImageRoute (W08 makes ImageRoute open design documents). Find out which
   stored items used to fall through (`preferLocal*` false, vector images, legacy formats) and give them a
   read-only + convert (if converter exists) result, never an iframe. Delete `workbench-embed.tsx` /
   `editor-protocol` / `hosted-editor` pieces that become unused; keep anything still used by UGC preview
   or MCP apps. Record in delivery exactly which stored formats now open read-only.
5. Merge theme id `design-canvas` into `image` routing per contract (coordinate in delivery with W08 if
   ImageRoute isn't ready; routing goes to ImageRoute regardless).
6. New guard test `tests/native-editors-guard.test.mjs`: (a) `PRO_PAGE_EDITORS` is exactly
   grid/pdf/website and `buildPluginPages` for every other editor id has no pro page; (b) no file under
   editor directories (`advanced-routes/`, `media-editors/`, `doc-editors/`, `image-editor/`,
   `video-editor/`, `website-local/`, `workflow-carrier/`) contains `<iframe` — allowlist only genuine
   UGC run sandboxes if any exist there (name each with reason); (c) no import of removed modules
   (AudioHostedFrame, Model3DHostedFrame, RichDocHostedRoute, DeckHostedRoute, ChartRoute, chart-editor,
   react-video-editor vendor, waveform-playlist). Part (c) will be red until other owners land — that is
   expected; parent runs it at integration.
Acceptance: focused tests for everything you touched green; your own files typecheck clean.
