# W02 — Audio editor: wavesurfer.js only, single mode, delete AudioMass hosted Pro

Goal: opening an audio item shows the user's waveform immediately in an OceanLeo-native editor
(single mode). Capabilities kept: everything the current normal mode does (load, play/seek, selection,
trim/cut/copy/paste/delete, fades, gain/normalize, multi-clip/multi-track if the current project
carrier has it, transcript panel, agent command surface, autosave/recovery/collab, export). No
"drop a file" empty state; no Pro page.

Owned cluster: `src/shell/media-editors/` audio files (Audio*.tsx, audio-*.ts, use-audio-*.ts,
waveform-playlist.d.ts, audio-playlist-*.ts, audio-next-*.ts, audio-checkpoint.*),
`advanced-routes/AudioRoute.tsx`, `collab/adapters/audio.ts`, audio tests.
Delete: `AudioHostedFrame.tsx`, `audio-hosted-embed.ts`, all pro/hosted branches, `waveform-playlist`
usage and its d.ts.

Engine: `wavesurfer.js` v7 (already installed, check `node_modules/wavesurfer.js/dist/plugins` for
regions, timeline, envelope, minimap, spectrogram, hover, record). Audio processing (cut/fade/gain/
normalize/mix-down/WAV encode) via Web Audio API in our own small module. If multiple tracks are part
of the stored project format, render one wavesurfer per track with our own track headers; do not
re-add a multitrack library unless installed. Keep the stored audio project format readable (do not
silently rewrite stored docs; a version bump with read-compat is fine).
Theme from plugin theme tokens. No upstream branding.

Note the known bug: the hosted init was only sent if the buffer was decoded before iframe ready —
irrelevant after deletion, but make sure the native editor shows content as soon as decode finishes
and shows a real error (not an empty canvas) if decode fails.

Request `waveform-playlist` removal from package.json in delivery (parent applies). Do not edit
library-viewers (W06 owns audio preview).
Acceptance: focused audio tests green (rewrite tests that asserted waveform-playlist/AudioMass),
regression test: no import of waveform-playlist / AudioHostedFrame anywhere under src; audio has no pro
page (use `buildPluginPages` from W01 if landed, else assert your route never calls usePluginMode).
