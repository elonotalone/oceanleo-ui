# W06 — PDF on EmbedPDF only + native Library previews (PDF, video, audio, canvas)

Goals:
1. PDF editor: normal mode = our UI on the EmbedPDF engine (existing PdfNextStage normal path); Pro =
   official `@embedpdf/react-pdf-viewer` (already wired in PdfNextStage). In Pro, disable the viewer's
   own open-file / download / print / save / export UI (use its config: disabledCategories /
   plugin config — read node_modules/@embedpdf/snippet types), apply OceanLeo theme colours, and make
   edits made in Pro save through our top bar (same document bytes, existing save path). If the viewer
   cannot be prevented from offering a save/download that bypasses us, report it precisely.
   Remove every pdf.js (`pdfjs-dist`) rendering path in src (thumbnails/preview raster included) in
   favour of EmbedPDF/pdfium; if something truly cannot move, list it. Request `pdfjs-dist` removal in
   delivery only if unused.
2. Library PDF preview (`library-viewers.tsx` ~L1660–1700): stop putting the PDF URL in an iframe
   (that shows Chrome's built-in viewer with annotate/draw tools that never save). Render with our
   EmbedPDF read surface (lazy loaded), read-only, with the existing ✏️ path into the editor. Remove the
   sandbox-exempt PDF frame allowlist if it becomes unused (security gate first).
3. Video/audio previews (`LibraryMediaPreview.tsx`, used by library-viewers): replace browser native
   `controls` with a small OceanLeo player (play/pause, seek bar, time, volume, fullscreen for video);
   no browser download/PiP menu (`controlsList`, `disablePictureInPicture`, no native controls).
4. `canvas` kind preview: design canvases now belong to the image type (00-dispatch). Show the
   rendition image like `image`, never `SandboxedWebViewer`; label 图片 in `libraryKindLabel`.
   Keep SandboxedWebViewer for real UGC (website/game/geo_map/interactive_doc/video workflow) unchanged.

Owned cluster: `src/shell/library-viewers.tsx`, `LibraryMediaPreview.tsx`, `src/shell/media-editors/`
pdf files (Pdf*.tsx, pdf-*.ts, use-pdf-*.ts, pdf-form/), `advanced-routes/PdfRoute.tsx`,
`collab/adapters/pdf.ts`, `use-pdf-collab.ts`, any pdf raster helper using pdfjs, related tests.
Acceptance: focused tests green; regression tests: library PDF preview renders no `<iframe`, media
preview has no native `controls`, canvas preview does not use SandboxedWebViewer.
