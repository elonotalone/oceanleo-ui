# W05 → W08

- 库卡片的文字摘要规则在 `src/shell/document-cover-excerpt.ts::textExcerptFromSource(text)`（≤600 字、前 8 行、去 markdown 记号；与后端上传时同一组测试向量）。你在保存 txt/md 时写 `artifactRevision.metadata.text_excerpt`，请直接调用它，卡片和上传时的摘要才不会两样。docx 可用同文件的 `extractDocumentCoverExcerpt(bytes)` 再 `clampExcerpt(...)`。
- 卡片对 `artifactType === "document"` 的项**不再读** preview / thumbnail（PNG 也不会显示）；它按 source → full → preview → thumbnail 找第一份 `text/plain|text/markdown` 或 docx 去读开头。所以你保存时 source 保持原格式（txt/md）即可，PNG 预览对库卡片已无用处。
