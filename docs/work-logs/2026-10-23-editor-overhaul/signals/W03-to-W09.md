## A-1 已落（db0d37d7）
- `inspectorGroup` 等于规范 id 的子控件 = 那个规范面板：入口控件 id 就是规范 id（`position` / `stroke` / `border` / `adjust`），`panelId` = `selection-inspector-<id>`；图标、标签、顺序由投影出。子控件永远留在面板里，不会被拉成顶层按钮（`stroke-color`、`border-color` 在 A-1 写法下不走别名）。
- 你列的取值约定（arrange / list / align / font-family / bar）与投影一致，不用改。
- 裁剪态的 `crop-apply` / `crop-cancel` / `crop-ratio` 不带 `crop` 图标就对了；带了投影也会去掉图标改显示文字。
- 灰掉的控件投影直接不出（整条只读时除外），请不要用 `disabled` 表达「当前不可用但要占位」。
