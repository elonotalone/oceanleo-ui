# W03 — 统一编辑栏：词表投影、删掉「编辑工具」图标、栏不被侧栏盖住（D3 D9）

## 用户看到什么（完成后）

- 任何编辑器里选中文字，看到的都是同一条文字栏：同样的按钮、同样的图标、同样的顺序（`00-dispatch.md` §4）。选中图片是同一条图片栏，选中形状是同一条形状栏，后面接同一个对象组。
- 同一条栏里没有两个长得一样的图标。操作员截图里 PPT 那条有三个差不多的「A」、两个一样的十字箭头，这种情况不再出现。
- 字体显示字体名，字号显示数字，文字颜色是带色条的「A」，高亮是荧光笔，对齐图标随当前值变化。
- 编辑栏最左边那个随选中对象变化的圆形「编辑工具」图标在所有编辑器里都没了。它藏着的抽屉由 W02 做成空态里带文字的按钮。
- 编辑栏不会被编辑器自己的侧栏盖住。操作员 PPT 截图里，栏的左端藏在幻灯片缩略图栏后面，连「页面」两个字都被截了一半。
- 收起成圆、拖动、停靠的行为照旧。

## 已知事实

- [读码] `SelectionToolbar.tsx`：
  - 前缀区在 `toolsAvailable` 时渲染 `EditorToolsTrigger`（`EditorToolsIcon.tsx`），图标由 `editorToolsIconForSelection(kind)` 选，点了调 `layout.toolsLauncher.toggle()`。
  - 工具面板的注册在 `InlineAdvancedWorkbenchHeader.tsx`，W01 会删掉。
  - `editorToolsIconForSelection` 还被收起后的小圆用作上下文图标，这个用法要保留。
- [读码] 规范化只做了一半：`selection-toolbar-layout.ts` 有 `DESIGN_TEXT_CONTROL_ORDER` 和 `CONTROL_ID_SEMANTICS`，`SelectionToolbar` 只在 `toolsLauncher?.id === "design-canvas"` 时按语义排序。设计画布在 10-22 已经并进 `image`，这个判断现在永远不成立。
- [读码] `SelectionControl` 已有 `semantic?: SelectionControlSemantic`（并集很窄）。图标并集 `SelectionControlIcon` 在 `selection-context-types.ts`，图标本体在 `AdvancedEditorIcon.tsx`。
- [读码] 各编辑器的 id 各写各的，这是你要做别名表的依据：
  - 删除线：deck / doc 用 `strike`，图片用 `linethrough`
  - 文字颜色：`color` 或 `text-color`
  - 翻转：`flip-x` / `flip-y`，也有 `flip-horizontal` / `flip-vertical`
  - 旋转：`rotate-left`、`rotate-right`、`angle`、`rotation` 都有
  - 层级：`layer-up` / `layer-down`
  - 字体：`font-panel`
- [实测，操作员截图] PPT 文字栏：`T` 高亮圈（触发器）｜`T A A A̲ B I U ≡ ↕ ⁘ 💧 ▷ ✥ ✥ …`。

## 要做

1. 先落接口，第一个提交争取 15 分钟内完成，因为别的 owner 要对着它改：
   - `selection-context-types.ts` 给 `SelectionContext` 加 `bar?: "text" | "image" | "shape" | "object"`。
   - 新建 `edit-bar-canon.ts`，导出 §4 的规范 id 表（分组、顺序、kind、图标名、中文标签）、别名表，以及 `canonicalSelectionControls(context)` 的签名。
   - 类型检查绿了就提交。
2. 投影（在 `SelectionToolbar` 里，对所有编辑器生效）：
   - 按规范 id（加别名）把控件改成规范图标、规范 `tt` 标签、规范顺序与分组。分组顺序是文字 → 图片 → 形状 → 对象 → 编辑器特有。
   - 同语义重复的合并成一个。编辑器特有控件排在后面或进「更多」。
   - 规范 id 的图标不许被别的控件借用：遇到冲突，特有控件改用通用图标或显示文字。
   - 没有 `bar` 时按 `kind` 推断。
   - 字体做成显示当前字体名的下拉，字号做成数字输入加下拉，对齐图标随当前值变化。
3. 图标：在 `AdvancedEditorIcon.tsx` 补齐缺的，包括 highlight（荧光笔）、text-color（带色条 A）、line-height、letter-spacing、clear-format、replace、radius、adjust、fill、stroke、arrange、indent 等，每个都要一眼能分清。
4. 删 `EditorToolsTrigger`：前缀区不再渲染它，`EditorToolsTrigger` 组件删除。`editorToolsIconForSelection` 保留给收起后的小圆用。相关测试改写。
5. 栏的位置：
   - 展开态的编辑栏不能盖住编辑器侧栏（缩略图栏、图层栏），也不能跑出舞台可见区。
   - 栏太宽时先折进「更多」，然后做水平约束；左边被挡住时栏要整体右移到可见区。
   - 先在 `floating-toolbar-geometry.ts` / `FloatingContextToolbar.tsx` 里修通用逻辑。编辑器侧栏若需要标出「这块别盖」，给出一个通用的 data 属性约定（例如 `data-edit-bar-avoid`），写进 `signals/W03-to-W07.md` 等对应信号，由各编辑器 owner 加。
6. 判据测试（新文件）：
   - 对 §4 每组，用一个假选区（每组规范 id 全给，加几个别名，加一个借用规范图标的特有控件）渲染 `SelectionToolbar`，断言可见按钮图标两两不同、顺序与表一致、别名被归一。
   - 断言前缀区不再有 `[data-editor-tools-trigger]`。
7. 浏览器：各编辑器 owner 改完之前，先用演示（已有文字框）和图片编辑器在浏览器里看投影后的栏，light 和 dark 都截图到 `evidence/W03/`。中途和收尾各看一次。
8. 文案写进 `editor-overhaul-copy-w03.ts`，包括所有规范标签的 16 语译文。

## 边界

- 你不改任何编辑器的路由或控件定义文件，它们由 W06–W16 自己改 id。
- 你的投影要能兼容它们改之前的旧 id，这就是别名表的用处，也是为什么它们改完之前你也能验收。
