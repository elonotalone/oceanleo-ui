# W08 — 文档（RichDoc / Tiptap）

先读 `tasks/_EDITOR.md`（A–E 全做）。本文件只写文档的特殊情况。

## 用户看到什么（完成后）

- 选中文字：统一文字栏（字体、字号、粗体、斜体、下划线、删除线、文字颜色、高亮、对齐、列表、行距、链接，「更多」里是缩进和清除格式）。段落样式（标题 1/2/3、正文）作为特有控件，排在文字组之后。表格、批注等特有控件排在后面。
- 选中图片：统一图片栏（替换、裁剪如果做得到、圆角、边框、透明度，「更多」里是环绕方式这类特有项）。
- 空态编辑栏：「插入」「批注」。
- 深色：正文区域变成深色，默认黑字显示为浅色，用户设过的其它颜色保留（只改显示，不改存储内容）。浅色和深色都要好读。
- txt、md、docx 都能连续保存、关掉重开都在。保存后回到库，卡片是**文字卡片**（标题 + 开头几行），不是渲染图。

## 已知事实

- [读码] 控件在 `doc-editors/RichDocContextToolbar.tsx`，旧 id 与规范 id 的对应：

  | 旧 id | 规范 id |
  |---|---|
  | `color` | `text-color` |
  | `bullet-list` / `ordered-list` | `list`（none/bullet/ordered） |
  | `clear` | `clear-format` |
  | `link` / `unlink` | `link`（取消链接放在 link 面板里） |
  | `indent-increase` / `indent-decrease` | 保留 |
  | `format` | 段落样式，特有控件 |

  `font-size`、`bold`、`italic`、`underline`、`strike`、`highlight`、`align`、`line-height` 不用改。
  表格类（`cell-*`、`row-*`、`column-*`、`table-delete`、`header-row`）和排版类（`cn-typography`、`first-line-chars` 等）是特有控件。
  需要时补 `font-family`（Tiptap FontFamily），做不到就写明。
- [实测，生产库只读] 被编辑过的 txt 和 md 文档，当前版本的 `preview`、`thumbnail` 是 PNG，所以库卡片一直转圈（截图里的 notes.txt、「需签字盖章页清单」）。没编辑过的，`preview`、`thumbnail` 就是源文本本身。
- 接口（`00-dispatch.md` §6）：
  - 保存文本类文档时，经 W04 的 `artifactRevision.metadata` 写入 `text_excerpt`（≤600 字，去掉 markdown 记号的前几行）。
  - txt、md 不再生成 PNG 预览，`preview`、`thumbnail` 用源文本本身，与上传时一致。
  - docx 要什么样的可展示主产物，先读 doc-io 的 renditions 计划，再与 W04 在信号里对齐。
  - W04 的透传落地前先做其它部分。
