# 编辑器 owner 的共同清单（W06–W16 都要读）

你负责的是**一件编辑器的完整体验**。下面五件事每件编辑器都要做完；你自己任务书里写的是这件编辑器的特殊情况。

## A. 统一编辑栏（D9，词表见 `00-dispatch.md` §4）

1. 把你的选区控件改成规范 id。文字用文字组，图片用图片组，形状用形状组，可移动对象再加对象组。给出 `bar`。
   - W03 的第一个提交会加上 `bar` 字段和 `edit-bar-canon.ts`。落地之前你先只改 id；类型检查报 `bar` 不存在时，等它落地后再加。
2. 你的引擎做得到、却还没有的规范项，要补上（例如文字的 `font-family`、`highlight`、`list`、`link`）。确实做不到的项不出，不放灰按钮。
3. 编辑器特有控件放在对象组之后，或者放进「更多」，**不许借用规范项的图标**；需要新图标时写 `signals/<你>-to-W03.md`，W03 会补。
4. 每个出现的按钮都要在浏览器里点一遍：画面上看得到效果，撤销能撤回，保存后重开还在。做不到的删掉，并写进交付。
5. 编辑器侧栏（缩略图栏、图层栏等）若会被浮动编辑栏盖住，按 W03 在信号里给的约定给侧栏加标记。

## B. 编辑栏空态与抽屉（D3）

W02 会把你 adapter 里的 `drawers`（或 `toolbox`）做成编辑栏空态里带文字的按钮。你要确认：
- 名字是人话，两到四个字。
- 每个抽屉打开后都能用。
- 不需要的抽屉删掉；AI 不要自己再申报。

## C. 深浅两档（D6 D7）

- 主题现在只跟随网站（W01 落地）。你这件编辑器的每个界面在 `THEME=light` 和 `THEME=dark` 下都要对：舞台底色、侧栏、面板、弹层、菜单、对话框、空态、加载态、错误态、编辑栏的下拉。
- 不许写死浅色（`bg-white`、`#fff`、`text-stone-900`、`text-black` 这类），一律用 `--awb-*` / `--pchrome-*` / 站点语义 token。
- 内容本身按 D6 处理：幻灯片、PDF 页面、图片、网站预览、视频画面、3D 场景保持原色；文档正文和表格格子跟着主题变（显示层把「默认黑字 / 默认白底」映射成主题前景和背景，用户明确设过的其它颜色保留，存储内容不改）。
- 原来默认深色的编辑器（视频、音频、3D、游戏、网站、视频画布）现在在浅色网站下是**浅色**。浅色要和深色一样精致，不是简单反色。
- 两档截图存 `evidence/<你>/`，交付里列出路径。

## D. 保存（D11，判据 `00-dispatch.md` §5）

- W04 修共享内核（基线前移、只 fork 一次、状态诚实）。你负责你这件编辑器的保存路径在浏览器里逐条通过 §5。
- 先跑一遍记录现状（多半在第 2 次保存失败），W04 交付后再跑一遍。查看方法：`signals/W04-state.md`、`verdicts/W04-delivery.md`。
- 你的路由里如果另有「拿旧基线」或「不报错」的路径，由你改。
- 共享内核的问题写 `signals/<你>-to-W04.md`，写清复现步骤。
- 每一次保存都核数据库（只读，验收账号）：版本数是否 +1，是否出现多余条目。

## E. 素材插入（D2）

确认你的 material adapter（`useWorkbenchMaterialAdapter`）对本编辑器能用的素材类型有主动作，点一下就插入。没有就补上，例如演示、文档、网站、视频插图片，视频还能插视频和音频。

## 交付里必须有

- 统一栏：你出的规范 id 清单、做不到而不出的项、特有控件清单。
- 每个按钮的浏览器点测结果。
- 两档截图。
- 保存协议逐条结果（附数据库核对）。
- 删掉的东西和原因。
