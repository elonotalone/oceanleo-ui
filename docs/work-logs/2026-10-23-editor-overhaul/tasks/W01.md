# W01 — 顶栏一行 + `···` 菜单 + 页签进顶栏 + 主题跟随站点（D1 D7）

## 用户看到什么（完成后）

每个编辑器顶部只剩**一行**：
- 左：`←` ｜ 素材库 我的库 ｜ 模式页签。页签只在 PDF、表格、网站（编辑 | 专业编辑）和游戏（编辑 | Code）出现，单模式编辑器没有页签。
- 右：`↶ ↷` ｜ 保存状态 ｜ `···` ｜ 全屏 ｜ `×`。
- `···` 菜单里有：邀请一起改、生成回放、分享、收藏，以及「下载 ▸」（子菜单列出各格式）。每项都有图标和文字，点了做的事和原来的按钮一模一样。
- 没有主题按钮。编辑器的明暗永远跟着网站当前主题走（auto 按系统解析，特色主题按明暗归入 light 或 dark）。
- 原来的第二行页签行整行没了，舞台多出 36px。
- 多人同改的头像串和锁提示留在 `···` 左边，不进菜单。

## 已知事实

- [读码] 第一行由 `AdvancedWorkspaceActionBar.tsx` 画（`PluginGlobalRow` 包了一层）。第二行页签由 `PluginPageRow.tsx` 画。两者都由 `InlineAdvancedWorkbenchHeader.tsx` 装配。有 SplitWorkspace 右栏时，整个 header 被 portal 进右栏的标题槽（`InlineAdvancedWorkbenchShell.tsx`，那是 W02 的文件，你只改 header 内部）。
- [读码] 分享 / 收藏在 `editor-item-social-chrome.tsx`；邀请一起改 / 生成回放在 `collab/CollabActionSlotInner.tsx`（`CollabInviteButton`、`replay/work/GenerateReplayButton`）；下载菜单在 `AdvancedWorkspaceActionBar.tsx`。
- [读码] 主题：`plugin-theme.tsx` 里每件插件有自己的「本命默认」（视频、音频、3D、游戏、网站默认 dark），存在 localStorage `oceanleo.plugin-theme.<id>`，再配一个 `PluginThemeToggle`。站点主题来自 `src/theme/ThemeProvider.tsx` 的 `useTheme().resolved`；没有 Provider 时退回 `html` 上的 class，用 `isLightAppearance` 判明暗。
- [实测，操作员截图] PPT 编辑器的顶栏是深色（右栏标题跟站点走），编辑栏、缩略图和舞台却是浅色（插件主题走自己的默认）——两个主题源打架。
- [实测，操作员截图] PDF 打开后顶栏没有保存状态的云朵。原因是 `AdvancedWorkspaceActionBar` 在 `adapter.persistence?.recovery?.ready === false` 时整个隐藏 save-state 槽，而 PDF 处理中会把 ready 置 false。按 §6，这个槽要恒在、如实显示。
- [读码] `PluginChromeFrame.tsx` 有自己的一套头（给 website / design / video 三个仓的陈列馆插件用；门户里的编辑器不用它）。它也要去掉主题键，并改用同一个 `···`。
- [读码] `plugin-pages.ts::GLOBAL_ROW_SLOTS` 被 `tests/plugin-chrome-global-row-allowlist.test.mjs` 读取。新的槽表是：`back` `library` `pages` `history` `save-state` `collab` `more` `maximize` `close`。`theme`、`share`、`favorite`、`download` 不再是第一行的独立槽，它们住进 `more` 里。

## 要做

1. 新建 `···` 菜单组件（文件放在 `plugin-chrome/` 下，名字自定）。
   - 复用 `AnchoredPopover` 与 `ui/Button`。键盘可达：Esc 关闭，方向键移动。
   - 菜单项：邀请一起改、生成回放（只有 `adapter.collab` 时才有）、分享、收藏 / 取消收藏（状态与原来一致）、下载 ▸。
   - 下载子菜单的条目 = `adapter.directDownload` + `group === "download"` 的动作，与现在的下载菜单逻辑相同。
   - 邀请和回放原来是带自己弹窗的按钮：给它们加一个菜单项形态（或暴露打开弹窗的方法），保证点菜单项后弹出的是同一个窗口。
2. `AdvancedWorkspaceActionBar` 改成一行：左 back / library / 页签（来自 `buildPluginPages`，只有一页时不渲染）；右 history / collab 头像串和锁 / save-state（恒在）/ `···` / maximize / close。删除主题槽。
3. `InlineAdvancedWorkbenchHeader`：删掉 `PluginPageRow` 那一行，切页逻辑（`usePluginPage`、aux 回调、`PluginModeAdapterBridge`）挪进第一行的页签。同时删掉 `toolsPanel` / `openTools` / `useAdvancedToolsLauncherRegistration`（W03 删了触发图标，这段成了死代码；`drawers` prop 可以先保留但不用）。
4. `plugin-theme.tsx`：`currentPluginTheme` / `usePluginTheme` 改成跟随站点外观。
   - 优先读 ThemeProvider 的 `resolved`。没有 Provider 时读 `document.documentElement` 的主题 class，并用 MutationObserver 跟随变化。
   - 删除 localStorage 读写、`PLUGIN_THEME_SPECS.defaultTheme` 的使用和 `PluginThemeToggle`。accent 表保留。
   - SSR 首帧与站点的首帧防闪（`ThemeScript`）一致，不许先闪一档再跳。
5. `PluginChromeFrame.tsx` 的头同步：去掉主题键，分享 / 收藏 / 下载走同一个 `···`。
6. 文案：新字（「更多」「邀请一起改」「生成回放」「下载」等）写进 `editor-overhaul-copy-w01.ts`，16 语齐全。
7. 测试：
   - 改写 global-row allowlist、save-menu、plugin-theme、plugin-mode 等测试，使其断言新行为。
   - 新增：「第一行只有一行，没有 `[data-plugin-page-row]`」「没有 `[data-plugin-theme-toggle]`」「站点切 dark 时编辑器根 `data-plugin-theme` 跟着变 dark」「save-state 在 recovery.ready=false 时仍渲染」。
8. 浏览器验收（验收账号，light 和 dark 各一遍，截图到 `evidence/W01/`）：
   - PDF、表格、网站、游戏、演示、视频，各打开一件。
   - 看顶栏一行、页签、`···` 每一项真的起作用（分享会复制链接；收藏后到库里看星标；下载会触发下载；邀请和回放能弹窗）。
   - 站点主题从 light 切到 dark（`THEME` 环境变量，或页面里的站点主题设置），编辑器整体跟着变。
