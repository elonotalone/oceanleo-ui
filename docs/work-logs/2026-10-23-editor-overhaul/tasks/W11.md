# W11 — 视频时间线：编辑栏每个按钮都生效（D10），统一文字 / 图片栏，深浅两档，保存

先读 `tasks/_EDITOR.md`（A–E 全做）。本文件只写视频的特殊情况。

## 用户看到什么（完成后）

- 选中时间线上的片段时，编辑栏里**每一个**按钮都在预览画面里立刻看得到效果，能撤销，保存后重开还在：
  - 文字片段：统一文字栏（字体、字号、粗体、斜体、文字颜色、对齐……做得到的项）→ 时间与转场等特有控件。
  - 视频、图片片段：统一图片栏里适用的项（透明度、旋转、翻转、调色 = 亮度 / 对比度 / 饱和度、适配方式）→ 位置面板（x / y / 缩放 / 角度）→ 特有控件（开始时间、时长、源内起点、速度、音量、静音、转场）。
  - 音频片段：音量、静音、速度、淡入淡出（引擎做得到的）。
  - 对象组：复制、删除。
- 做不到的按钮不出现。删了哪些，交付里逐个写清楚。
- 原来默认深色。现在浅色网站下是精致的浅色（时间线轨道、片段色、标尺、面板），深色网站下仍是深色。
- 保存：剪辑、改字、调参数后关掉重开，全都在。

## 已知事实

- [实测，操作员原话] 「视频编辑插件中的 edit bar 按键基本都没用」。
- [读码] 控件在 `video-editor/VideoTimelineContextToolbar.tsx`：`start-time`、`duration`、`source-in`、`text`、`font-size`、`color`、`bold`、`align`、`volume`、`muted`、`speed`、`fit`、`scale`、`opacity`、`rotation`、`x`、`y`、`brightness`、`contrast`、`saturation`、`transition`、`transition-duration`、`duplicate`、`delete`。
  - 命令执行与模型：`use-video-timeline.ts`、`timeline-model.ts`、`video-command-surface.ts`。
  - 预览：`preview-engine.ts` / `VideoTimelineStage.tsx`。
  - 导出：`render-client.ts`。
- [待核] 按钮「没用」的原因可能有几种：命令没接上，模型改了但预览没重绘，值越界被吞，或者编辑栏发出的 `controlId` 和执行端对不上。逐个复现，记 journal。
