# V03 — 编辑栏与按钮的独立验收（D3 D4 D9 D10）

先读 `tasks/_VERIFY.md`。

## 判据

1. **D9 统一栏。** 在每个有文字、图片、形状对象的编辑器（文档、演示、图片、网站、视频、PDF 加文字、表格单元格）里分别选中：
   - 规范项的顺序与 `00-dispatch.md` §4 一致；同一条栏里没有两个相同的图标（DOM 里读图标标识或 svg 指纹，并截图）。
   - 同一个规范项在不同编辑器里图标和标签一样。
   - 没有灰掉的占位按钮。
2. **每个按钮都有用。**
   - 每个编辑器、每种选区、每个可见按钮都点一次。对比点击前后的截图或 DOM / 模型读数，判断是否看得到效果；点撤销能撤回。
   - 视频编辑器（D10）要逐个按钮记录。
3. **D3。**
   - 编辑栏最左没有「编辑工具」图标。
   - 空态里的抽屉按钮可用。
   - 栏不被编辑器侧栏遮挡（演示的缩略图栏是重点）。
4. **D4 PDF。**
   - 基础编辑：高亮（换颜色）、下划线、删除线、✓、✗、加文字、签名（手写和打字各一次，重开后签名还在列表里可复用）、画笔、便签、查找，每样都试。
   - 缩略图：旋转、删除、拖动排序。
   - 不存在提取页、插空白页、合并 PDF。
   - 「编辑」与「专业编辑」来回切换 5 次：不出现「正在切换」，不重新载入；页码、缩放、未保存的批注都在。
   - 只有一个缩放控件。
   - 保存后下载 PDF，用独立方式确认批注是标准注释：python `fitz` 可用就用，否则解析 `/Annots`。
