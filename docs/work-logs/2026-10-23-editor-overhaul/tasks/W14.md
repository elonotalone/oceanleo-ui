# W14 — 网站（Puck）

先读 `tasks/_EDITOR.md`（A–E 全做）。

## 用户看到什么（完成后）

- 在网站预览里**点一段文字**：编辑栏出现统一文字栏。只出组件支持的项，比如字号、粗体、斜体、文字颜色、对齐、链接。改了预览立刻变，能撤销，保存后重开还在。
- **点一张图片**：编辑栏出现统一图片栏（替换、圆角、边框、透明度、适配方式、替代文字……组件支持的项）。
- 点任何区块，对象组都有：上移 / 下移（`arrange`）、复制、删除。
- 「专业编辑」是 Puck 完整界面，和「编辑」是同一个 Puck 实例，切换无缝，选中状态和数据都在。
- 深色：Puck 的面板、字段、外框都是深色；网站预览本身保持网站自己的颜色（D6）。
- 保存：改了文字和图片，关掉重开都在。
