# V02 — 保存的独立验收（D11，11 个编辑器）+ 清理清单复核

先读 `tasks/_VERIFY.md`。

## 判据

`00-dispatch.md` §5 的五条，对下面 11 个编辑器逐个判：

| # | 编辑器 | 素材来源 |
|---|---|---|
| 1 | PDF | 上传 |
| 2 | 演示 | 上传 pptx 和公共模板各一件 |
| 3 | 文档 | txt、md、docx 各一件 |
| 4 | 图片 | 上传 png，另取一件公共设计素材 |
| 5 | 表格 | 上传 xlsx |
| 6 | 视频 | 上传 mp4 |
| 7 | 音频 | 上传 mp3 |
| 8 | 3D | 上传 glb |
| 9 | 网站 | 公共模板 |
| 10 | 游戏 | 公共游戏 |
| 11 | 视频画布 | 公共模板 |

1. **自己的文件**：改 → 已保存 → 再改 → 已保存 → 关闭 → 重开，两处都在；刷新后也在。
2. **库卡片**跟着更新。
3. **公共素材**：第一次改动 fork 出**恰好一份**，编辑器和地址栏切到那份；之后的保存都进这一份。
4. **断网**（`context.setOffline(true)`）：显示「保存失败」并可重试；恢复网络后重试，变成「已保存」。任何时刻不许出现服务器没确认的「已保存」。
5. **数据库核对**（只读，只查验收账号）：每次「已保存」都对应 +1 个 revision；没有多余的库条目，也没有多余的隐藏 root（W04 交付后才算这一条；交付前记现状）。

## 另外

- W04 交付后，读它的清理脚本，只跑 dry-run（不许 `--apply`）。核对两张清单：
  - 4 个可见测试残留加 10 个同源隐藏项。
  - 无引用的 `editorInternal` root。抽 10 个查它们确实没有被任何现存 revision 引用（renditions、blob claims、editor_manifest 都要看）。
- 结论写进裁决。父 agent 只在你判这份清单可靠之后才执行。
