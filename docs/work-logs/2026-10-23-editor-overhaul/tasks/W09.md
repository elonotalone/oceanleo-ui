# W09 — 图片（Fabric，含原设计画布）

先读 `tasks/_EDITOR.md`（A–E 全做）。本文件只写图片编辑器的特殊情况。

## 用户看到什么（完成后）

- 选中文字图层：统一文字栏 → 形状项 → 对象组。
- 选中图片图层：统一图片栏（替换、裁剪、水平翻转、垂直翻转、旋转、圆角、边框、透明度、调色）→ 对象组。
- 选中形状：形状栏 → 对象组。
- 空态编辑栏：「画笔 / 形状 / 线条 / 便签」（现在只能从那个坏掉的图标进去，W02 做成按钮后由你确认都好用）。
- 深色：画布四周和面板是深色，画板 / 图片本身保持原色。
- 保存：
  - 改自己上传的图片：在**同一个**库条目上出新版本，不再生成「-编辑版」副本。
  - 从公共素材打开：只 fork 一次。

## 已知事实

- [读码] 控件在 `image-editor/fabric-image-toolbar-controls.ts`，旧 id 与规范 id 的对应：

  | 旧 id | 规范 id |
  |---|---|
  | `font-panel` | `font-family` |
  | `linethrough` | `strike` |
  | `char-spacing` | `letter-spacing` |
  | `text-case` | `case` |
  | `stroke` + `stroke-width` | `stroke` 面板 |
  | `rotate-left` / `rotate-right` / `angle` | `rotate`；角度放进 `position` 面板 |
  | `position-x` / `position-y` / `object-width` / `object-height` | `position` 面板 |
  | `replace-panel` | `replace` |
  | `filter-panel` | `adjust` |
  | `layer-up` / `layer-down` | `arrange` |
  | `crop-*` | `crop` 进入裁剪态；裁剪态里的比例、应用、取消是特有控件 |
  | `shadow` | 「更多」 |

  `table-*` 是特有控件。命令执行在 `fabric-image-commands.ts`。
- [读码] `SelectionToolbar` 里 `canonicalDesignText` 认的是 `design-canvas`，合并后已经失效。W03 会改成对所有编辑器统一投影，你不用管那段。
- [实测，生产库只读] 操作员库里有 300 多个「-编辑版」图片，大多是 7–9 月旧行为留下的。10-21 那批「[客户端验收] 图片-编辑版-编辑版…」是一层 fork 套一层 fork。你要证明现在改自己的图片不会再生成副本。
