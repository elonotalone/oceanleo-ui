# V01 — 外壳与库的独立验收（D1 D2 D3落点 D5 D7 D8，各承载）

先读 `tasks/_VERIFY.md`。

## 判据

1. **D1 顶栏一行。**
   - 11 个编辑器各开一件，看以下各项：
     - 只有一行；没有页签行；没有主题键。
     - `···` 里有邀请、回放（有协作时）、分享、收藏、下载 ▸。每一项都真的起作用：分享复制链接；收藏后库里有星标；下载触发下载；邀请和回放弹出窗口。
     - 保存状态始终可见（PDF 也要有）。
   - 页签：PDF、表格、网站显示「编辑 | 专业编辑」，游戏显示「编辑 | Code」，其它编辑器没有页签。
   - 窄窗口 `VIEWPORT=1024x768` 下不换行、不溢出。
2. **D2 面板。**
   - 承载：`/library?item=`、`/advanced/<featureId>`、工作台右栏（找得到入口就测，找不到写明）。
   - 每种承载点「素材库」「我的库」都能看到左侧面板。
   - 素材库第一项是「从本地上传」，点素材能插进当前文件。
   - 我的库点另一件：先保存，再切换，地址栏跟着变。
3. **D3 落点。**
   - 编辑栏最左的「编辑工具」图标在所有编辑器都没了。
   - 空态编辑栏有带文字的抽屉按钮：演示是模板、元素、画笔、线条、便签；文档是插入、批注；图片是画笔、形状、线条、便签。点了打开对应面板。
   - 编辑栏里只有右端一个 AI。
4. **D5 类型名。**
   - Type 菜单里没有 editing、编辑字样，没有「设计画布」。
   - 原设计画布素材归在「图片」下。
   - 中文、英文都看，`NEXT_LOCALE` cookie 切语言。
5. **D7 跟随主题。**
   - 站点 light 时编辑器整体是浅色，dark 时整体是深色。
   - 浅色时顶栏、编辑栏、舞台四周不出现深色块，深色时同理不出现浅色块。只做外壳层面的判断，编辑器内部细节归 V04。
6. **D8 文档卡片。**
   - 上传 txt、md、docx，库里直接显示标题和开头几行，不转圈。
   - 用文档编辑器改过再保存，仍是文字卡片，摘要更新。
   - 深色下卡片是深色。
