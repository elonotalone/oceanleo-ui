# W10 — 表格（Univer）

先读 `tasks/_EDITOR.md`（A–E 全做）。本文件只写表格的特殊情况。

## 用户看到什么（完成后）

- 「编辑」页（Univer 关掉了 ribbon）里选中单元格，编辑栏是统一文字栏：
  - 字体、字号、粗体、斜体、下划线、删除线、文字颜色、高亮（= 单元格底色）、对齐。
  - 之后是表格特有控件：垂直对齐、自动换行、合并、边框、数字格式，以及已有的行列、数据、条件格式、数据验证等。
- 「专业编辑」仍然是 Univer 完整 ribbon，和现在一样**无缝**切换（同一实例）。
- 深色：格子、表头、编辑栏、Univer 的菜单和 ribbon 都是深色；默认黑字显示为浅色，用户设的底色、字色保留。
- 保存：上传的 xlsx 连续改动后关掉重开，改动都在；下载出来的 xlsx 也包含改动。
