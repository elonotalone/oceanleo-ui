# V04 — 深浅两档的独立视觉验收（D6 D7：全部编辑器 + 外壳 + 库）

先读 `tasks/_VERIFY.md`。

## 判据

1. **范围**：11 个编辑器，加库页和外壳面板（素材库、我的库、`···` 菜单、编辑栏下拉与更多、对话框）。每个界面在 `THEME=light` 和 `THEME=dark` 下各截一张。
2. **深色下不许有浅色岛**（白底面板、白色弹层、白色缩略图栏、白色时间线），**浅色下不许有深色岛**。原来默认深色的编辑器（视频、音频、3D、游戏、网站、视频画布）在浅色下必须是精致的浅色。
3. **内容按 D6 处理**：
   - 保持原色：幻灯片、PDF 页面、图片、网站预览、视频画面、3D 场景。
   - 跟随主题：文档正文与表格格子；默认黑字在深色下可读，用户设的颜色保留。
4. **可读性**：两档下所有文字与背景的对比度达到 WCAG AA。抽查关键文字，算 4.5:1，大字 3:1，用 `page.evaluate` 读计算后的颜色来算。
5. **切换主题时整体跟着走**：站点主题切换后，打开着的编辑器立即跟随（不刷新页面，看根节点的 `data-plugin-theme` 与可见颜色）。

## 交付格式

一张「编辑器 × 界面 × 主题」的表，每格写：绿，或红加截图路径；红的同时写进对应 owner 的信号文件。

## 素材

全部用验收账号，标题带 `[V04]`。
