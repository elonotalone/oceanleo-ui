# W07 — 演示（deck）

先读 `tasks/_EDITOR.md`（A–E 全做）。本文件只写演示的特殊情况。

## 用户看到什么（完成后）

- 选中文字框：统一文字栏 → 适用的形状项（填充、描边、圆角、透明度）→ 对象组（层级、位置、动画、锁定、复制、删除）。不再出现三个相似的「A」和两个一样的十字箭头。
- 选中图片：统一图片栏 → 对象组。选中形状：形状栏 → 对象组。
- 空态的编辑栏有「模板 / 元素 / 画笔 / 线条 / 便签」（W02 生成，你确认每个都好用）。
- 编辑栏不再被左侧幻灯片缩略图栏盖住。
- 深色：缩略图栏、舞台底色、所有面板都是深色，幻灯片本身保持原色。
- 保存：连续改动、关掉重开都在；从公共演示模板打开会 fork 出一份。

## 已知事实

- [读码] 控件定义在 `doc-editors/DeckContextToolbar.tsx`，旧 id 与规范 id 的对应：

  | 旧 id | 规范 id |
  |---|---|
  | `font-panel` | `font-family` |
  | `color`（文字） | `text-color` |
  | `position-panel` | `position` |
  | `border-color` + `border-width` | `stroke` |
  | `border-radius` | `radius` |
  | `replace-panel` | `replace` |
  | `filter-panel` | `adjust` |
  | `layer-up` / `layer-down` | `arrange` |
  | `effects-panel` / `shadow` | 「更多」里的 `shadow` |
  | `fill` | `fill` |
  | `opacity` | `opacity` |

  另外 `edit-text`（进入文字编辑）是特有控件，图标不许用 `T`/`A`；也可以不出，双击文字直接编辑。
  命令执行在 `deck-toolbar-command.ts` 和 `use-deck-editor.ts`。
- [读码] 抽屉在 `advanced-routes/DeckRoute.tsx`（模板 `deck-design`、元素 `deck-elements`、画笔、线条、便签），后三者带 `hiddenFromRail`。
- [实测，操作员截图] 深色网站下，顶栏是深色，编辑栏、缩略图栏、舞台底色却是浅色。根因是主题源打架，W01 修；剩下的浅色岛由你清。
- 拿到演示的办法：上传 `harness/fixtures/sample.pptx`（看它是作为 deck 打开，还是走「一键转换」），或者从素材库 / 公共素材打开一份演示模板（会 fork）。两条都要跑通。
