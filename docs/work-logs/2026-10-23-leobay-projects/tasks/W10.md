## 要做的（操作员原话见合同第 6 条）

1. **两列**：左列上面是「任务」（白色圆角卡片，标题「任务」，内容即 `ProjectTasksTab`），紧贴下面是输入框——输入框只在左列宽度内，**不伸到右列下面**。右列整列是「项目配置」，从页面顶部内容区一直到底。
2. **右列顶上两张小卡片**：「动态 / Activity」（最近 2–3 条 + 「查看全部」→ `ProjectModal` 里放 `ProjectFeedTab`）、「计划 / Plan」（待办按状态的计数 + 前 3 条 + 「打开」→ 弹窗里放 `ProjectPlanTab`，可在弹窗里改）。接着「资产 / Assets」卡片（文件数 + 最近几个 + 「打开」→ 弹窗里放 `ProjectAssetsTab`）。再下面是原有的指令 / 连接器 / 专家 / 技能 / 自动化。空数据时卡片给一句清楚的空态 + 主操作（如「添加待办」「上传文件」）。用 `ProjectConfigCard` 的 `count` / `summary` / `openAction`。弹窗尺寸足够放下计划与资产（宽约 960px，高随屏幕）。
3. **去掉白色通栏**：顶部（面包屑、改名、星标、删除、邀请）直接坐在页面底色上；输入框周围不加白底（输入框自己的框保留）；右列外层不再是白底面板，只留一张张白卡片（白色只用来分隔，§5.3）。
4. 去掉主区四个页签（只剩任务）；窄屏：右列仍收进「项目配置」抽屉，抽屉里是同样的卡片顺序。
5. `ProjectWorkspaceFrame` 是共享件：可以加可选 props（例如 `bottom` 只占主列、`plain` 去白底），默认行为由你决定，但 `ProjectTabNav`（I-5）导出名与 props 不许变（W04 在用）。
6. 翻译：你边界内所有用户可见中文过 `tt()`，补齐 17 语种（「动态」「资产」「项目配置」等）。
7. 测试：`tests/project-workspace-primitives.test.mjs` 等被打红的改绿；新增 `tests/lbp-w10-project-layout.test.mjs`（输入框只在主列、右列卡片顺序、无白色通栏、弹窗打开）；共享 UI 与门户 typecheck 不新增错误。
