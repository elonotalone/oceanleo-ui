## 要做的（操作员拍板 + 父 agent 定案）

1. 页签改成 `ProjectTabNav` 同款下划线样式（直接用它）。三块：**交易**（英文 "Listings & orders"）/ **我的主页**（"My page"）/ **数据面板**（"Dashboard"）。
2. 「交易」里一行两个下拉（W01 的共用件 `BayFilterSelect`，你只传参）：第一个选 我发布的 / 我卖出的 / 我买到的 / 我的收藏（英文 Published / Sold / Purchases / Favorites，首字母大写）；第二个是类别：全部类别 / 现成文件 / 人工服务 / 网站与软件服务 / 课程 / 其他。删掉胶囊条。「成品文件」改「现成文件」。
3. 地址兼容：`mine:published|sold|bought|favorites` 打开「交易」并选中对应列表；`mine:page`、`mine:dashboard` 不变；`openMine()` 默认进「交易·我发布的」。`BayMineTab` 类型与 `bay-links.ts` 不改（不归你），在 `BayMine.tsx` 内做映射。右侧小窗（overlay 变体）同样能用。
4. 去掉整页白板：`PAPER_DETAILS` 去掉 `mine`、`dashboard`（发布、编辑类保留白板）。页签与下拉直接坐在页底；列表区放一块白色圆角卡片（参考项目页主区卡片：`rounded-xl border border-neutral-200 bg-white`）。数据面板、我的主页内部的卡片分别由 W05、W06 做，你只保证外框不铺白。
5. 「我买到的」（`mine/MyBoughtPane.tsx`）每一行显示付款金额；有订单（合同）的行加「查看对账单」，用 `settings/money-ui.tsx` 的 `StatementPanel` + `useBayMoneyLocale`（I-6）和 `lib/bay/money.ts` 的 `fetchBayStatement`、`formatBayFen`（只读引用，不改那两个文件）。
6. 英文大小写：在 `bay-shell-copy.ts` 的 en 段把 myPublished→"Published"、myHome→"My page"、dashboard→"Dashboard"（只改这三处值，别的不动）；其他语种若同样有小写问题一并只改值。
7. `LeoBayPage.tsx` 页头搜索提示改成不列种类名（如「搜索 LeoBay」/ "Search LeoBay"）；`BayDetail.tsx` 里「我的」相关标题与任何退役种类名按 §5.1 改。
8. 测试：被打红的 `tests/*`（`grep -l "BayMine\|MineCategoryBar\|PAPER_DETAILS\|data-mine-tab\|mine-category" tests/*.mjs`）改绿；新增 `tests/lbp-w04-mine.test.mjs` 覆盖三块、两个下拉、地址兼容、无整页白板、我买到的金额。
