# W03 · LeoBay 其余文件的种类名字清扫 + 发布表单统一

先读 `../_COMMON.md`（尤其 §5.1）。你的分表：`src/i18n/ui/messages/lbp-w03-copy.ts`。

## 背景（父任务已验）

操作员拍板：种类名一律用 人工服务 / 现成文件 / 网站与软件服务 / 课程 / 其他，「服务 / 素材 / 作品」作为种类名退役，「成品文件」改「现成文件」。LeoBay 界面里带「作品」的文案约 73 句、带「素材」约 14 句，分散在下面清单的文件里（父 agent 数过：AppPane 10、MyAppsPane 8、LibraryWorkPicker 7、AppLoginConsentPane 6……）。发布表单 `src/shell/bay/form/bay-listing.ts` 用「现成文件」，「我的」用「成品文件」——统一成「现成文件」（「我的」那边由 W04 改）。

## 要做的

1. 逐文件过清单，凡是**指代一个种类**的「服务 / 素材 / 作品」改成新名字；泛指一件东西的按 §5.1 自然改写（「作品页」→「详情页」等），**一句一句看，不许批量替换**。注意「作品」有时指用户文件库里的作品（如 `needs/LibraryWorkPicker.tsx`「从我的作品里选」）——判断清楚，不是种类的不改，并在交卷里列出「判定为非种类、保留」的句子。
2. 新文案过 `tt()`、进你的分表（17 语种）。已有中文原文且译文正确的直接复用。
3. 发布表单（`form/*`、`seller/*` 中你边界内的）里种类选项、说明、预览与 §5.1 表完全一致。
4. `src/pages/settings/sections/AutomationSettingsSection.tsx` 里「上架到 Bay」等相关文案按同一规则检查。
5. 跑与改动文件相关的测试（`grep -l` 找引用这些文件或这些中文串的 `tests/*.mjs`），打红的改绿（精确替换）；跑文案闸 `tests/i18n-tt-key-coverage.test.mjs`。
