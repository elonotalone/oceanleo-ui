## 要做的

1. **筛选类**（任务类型/来源/状态、计划的归属/来源/状态、资产类型）全部换成 `CollectionFilterSelect`（`@oceanleo/ui/shell`，W01 改了外观；只写当前值），「全部」项自带名词（全部任务 / 全部来源 / 全部状态 / 全部负责人 / 全部类型）；用 `"all"` 当全部的传 `defaultValue="all"`（W01 新增的可选 prop；若 W01 还没提交，先按现有 props 写，交卷前补上）。
2. **表单类**（待办编辑的状态/负责人/来源、批量状态、自动化频率、邀请权限）换成 `MenuSelect`（`@oceanleo/ui/shell`，I-1，props 以 `/root/projects/oceanleo-ui/src/shell/menu-select.tsx` 为准）。`<details>` 菜单改成与新菜单一致的弹出清单（或说明保留理由）。
3. **计划页翻译**：`ProjectPlanTab.tsx` 所有用户可见文字（含 aria-label、placeholder、空态、按钮、状态名、日期兜底文案）过 `tt()`，17 语种进你的分表。任务页「来源」原始值给出翻译后的名字（先查这些值从哪来、有哪些，列进交卷）。其余你边界内文件里写死的中文同样处理。

5. 测试：新增 `tests/lbp-w11-project-selects.test.mjs`（放在 `/root/projects/oceanleo-ui/tests/` 下，用源文件文本断言：无原生 `<select>` 残留、计划页无写死中文、选项与「全部」文字）；门户 typecheck 不新增错误；文案闸绿。
