## 今天（父任务已验，这是操作员定为「严重错误」的缺陷）

- 后端把平台通知写进 `user_notifications`（`backend/app/notifications.py` 的 `notify()`）：LeoBay 33 种交易事件、内容被隐藏/下架（`app/moderation/actions.py`，附「15 日内可提交反通知」）、举报处理结果、计费、任务交付、团队邀请等。读接口：`GET /v1/notifications`、`GET /v1/notifications/unread-count`、`POST /v1/notifications/read`、`POST /v1/notifications/read-all`；共享 UI 客户端 `src/api/notifications.ts`（`listNotifications` / `notificationUnreadCount` / `markNotificationsRead`）。
- 网页上**唯一**读它的是铃铛 `src/shell/account/NotificationBell.tsx`，约 102 行 `if (imOn || bayOn) return null`；而 `src/shell/messages/messages-family.ts` 的 `imEnabledFor` 对**两版都只看是否登录**。结果：境内、海外网页登录后都看不到任何平台通知；LeoChat 网页版也不读它。库里现有 35 条通知 34 条未读。
- 手机 App 在 Messages 里有「通知」屏（只读参考：`/root/projects/oceanleo-app/mobile/src/features/messages/NotificationsScreen.tsx`、`present.ts`），网页要与它对齐。
- LeoChat 视图模型 `src/shell/messages/host-state.ts`：`MessagesView = "inbox" | "people"`，深链参数 `IM_PARAM = "im"`，解析 `parseImDeepLink`（约 75 行）；布局 `MessagesLayout.tsx`、收件箱 `Inbox.tsx` / `InboxRow.tsx`；整页 `src/shell/leochat/LeoChatPage.tsx`、侧栏入口 `LeoChatButton.tsx`。

## 要做的（操作员：海外版与境内版的 leo message 功能必须完全一样）

1. **LeoChat 里的通知**：收件箱最上方固定一行「通知 / Notifications」（显示未读数和最新一条标题），点开进 `notices` 视图：通知列表（标题、正文、时间、已读/未读），点一条标为已读并跳到它的链接；「全部标为已读」。整页与小窗都可用，境内外**同一套代码路径，不按域名分叉**。
2. **链接落点**：站内链接在站内打开——LeoBay 链接（`/bay?bay=…`、订单、需求等）走 `openBay`/现有 Bay 深链；LeoChat 会话链接打开对应会话；内容处置（`kind === "moderation"` 或链接含 `/account/content-cases`、`/settings/content-cases`、`?im=cases`）打开 `cases` 视图；其余外链新窗口。
3. **`cases` 视图**（I-3、I-4）：`?im=cases` 打开、`?im=cases:<id>` 直接展开那一件；视图内容挂 `src/shell/messages/cases/MessagesContentCases.tsx` 的 `MessagesContentCases`（W09 实现；你只挂载、传 `caseId` 与 `onBack`）。它不出现在任何常驻导航里——平时不显示，只经通知或深链进入。
4. **未读数**：侧栏 LeoChat 入口与标签页标题的未读数把通知未读也算进去（沿用现有 IM 未读的显示位置）；新通知到达的刷新：沿用铃铛原来的轮询节奏或已有实时通道，选一个能证明的。
5. **铃铛**：登录后它两版都不显示、未登录又没有通知——从 `SidebarAccountCluster.tsx` 拿掉；若别处仍引用就保留文件但不渲染，交卷说明。
6. 测试：`tests/im-host-state.test.mjs`、`tests/im-inbox.test.mjs`、`tests/im-nav-entry.test.mjs` 等被打红的改绿；新增 `tests/lbp-w08-notices.test.mjs` 覆盖：两版 `imEnabledFor` 下通知行都出现（显式断言不分叉）、`?im=notices` / `?im=cases[:id]` 解析与序列化、链接落点分类、未读合计。
