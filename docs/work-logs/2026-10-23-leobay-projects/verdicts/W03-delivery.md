# W03 交卷 · LeoBay 其余文件的种类名字清扫 + 发布表单统一

owner：W03（Sonnet 5.5，重派）　日期：2026-10-23　仓：`/root/projects/oceanleo-ui`（只改共享 UI，没碰门户 / 后端）

## 0. 一句话

边界内 151 个文件、187 行带「服务 / 素材 / 作品 / 成品」的文字逐句过了一遍：指代种类的全部换成 §5.1 的五个名字或「网站或软件 / 商品 / 文件」这类按句子自然的说法，非种类的 18 句逐条判定保留（理由在第 3 节）。新词条 59 句 × 16 语写进 `src/i18n/ui/messages/lbp-w03-copy.ts`，文案闸里没有一条缺口落在 `bay/` 或设置目录。

## 1. 用户看到什么变化

## 4. 措辞规则（供 V01 和别的 owner 对口径）
